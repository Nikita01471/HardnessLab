# Hardness Lab — Android source v0.2

Тёмное офлайн-приложение на Kotlin. Без истории и без экспорта. Три вкладки: Виккерс, Бринелль, Минимальная толщина.

## Сборка
Откройте каталог `HardnessLab` в Android Studio с JDK 17 и Android SDK 35. После Gradle Sync выберите **Build → Build APK(s)**. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

В данном окружении нет Android SDK/Gradle, поэтому APK не собран и приложение не тестировалось на устройстве.

## Источники
- `Замер твердости по Виккерсу + Бринелль v. 2.xlsx` — базовые калькуляторы.
- `Минимальная толщина образца ТВЕРДОСТЬ (версия 2.0).xlsx` — таблицы толщины.

`app/src/main/assets/thickness_tables.tsv` содержит извлечённые значения справочных таблиц Excel для Роквелла, Виккерса (ГОСТ Р ИСО 6507-4-2007, ГОСТ 2999-59, ГОСТ 9450-76) и Бринелля (ГОСТ 9012-59). Поиск ближайшего меньшего значения реализован как приближение к VLOOKUP(..., TRUE). Вводится HB; HV вычисляется по формуле Excel ROUND(HB*1.05,0); HRC по формуле из исходной книги. Для Бринелля **пока не полностью перенесены условия допустимости нагрузок, геометрии отпечатка и специальные предупреждения из Excel**: табличный результат не означает разрешённый режим испытания. Нужна верификация по эталонным значениям и испытаниям перед производственным применением.

Приложение не является официальной реализацией ГОСТ.
