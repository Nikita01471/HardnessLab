# HardnessLab 3.4 RC2

Офлайн-приложение для Android: Виккерс, Бринелль, минимальная толщина, переводы твёрдости. Тёмный компактный интерфейс, расчёт при вводе, отдельная история измерений и среднее, кнопки «Ввод», «Очистка» и «Очистить данные».

## Статус

Это кандидат для проверки, не производственный релиз. Вкладка перевода восстановлена по 12 отдельным сериям РТМ, ISO 18265:2013 и ASTM E140-12b (2019)e1. Пары, отсутствующие в таблице или не рекомендуемые для выбранного диапазона, не выдаются как достоверные. Подробнее: [CONVERSION_AUDIT.md](CONVERSION_AUDIT.md). Исходный числовой справочник сохранён; новая редакция ASTM E140-26 не верифицирована.

## Проверка и сборка

1. Подготовить JDK 17, Android SDK 35, build-tools 35.0.0 и Gradle 8.9.
2. `node tools/verify_data.mjs` — независимая проверка исходных данных и примеров Excel.
3. `gradle --no-daemon testDebugUnitTest` — выполнить JUnit-регрессии.
4. `.github/workflows/build-apk.yml` использует существующие GitHub Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) и собирает `app-release.apk`. Не изменять ключ или applicationId. Сверить отпечаток сертификата APK с предыдущей релизной версией.

Подписанный APK не включён. Не устанавливать его на рабочее устройство до проверки в отдельной среде и завершения нормативной сверки.

## Источники

- `Замер твердости по Виккерсу + Бринелль v. 2.xlsx` — базовые калькуляторы, предоставленный файл.
- `thickness_tables.tsv` — существующие справочные данные минимальной толщины (исходный Excel v2.0 полного справочника не предоставлен).
- `hardness_conversion.tsv` — неизменённый архивный справочник, не подтверждённый полностью; статус и решения по каждой группе в `CONVERSION_AUDIT.md`.

Приложение не является официальной реализацией ГОСТ, ISO или ASTM.
