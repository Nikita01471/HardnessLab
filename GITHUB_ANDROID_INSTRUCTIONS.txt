HardnessLab 3.4 RC1 — подготовка к сборке

1. Архив содержит только актуальное дерево исходников, без секретов, старых копий и вложенных ZIP.
2. В корне: build.gradle.kts, settings.gradle.kts, app, .github/workflows/build-apk.yml.
3. Проверить CONVERSION_AUDIT.md и оставшиеся ограничения. Не публиковать как окончательный релиз до проверки.
4. GitHub Actions запускает testDebugUnitTest, восстанавливает прежний release.jks из KEYSTORE_BASE64 и собирает assembleRelease. Не создавайте новый ключ для обновления существующего приложения.
5. Артефакт после успешной сборки: HardnessLab-release (app-release.apk). Сравните отпечаток сертификата с предыдущим APK при проверке подписи.
6. Производственные испытания/установка APK — только после завершения нормативной сверки и проверки интерфейса.
